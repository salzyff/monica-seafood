# Photo placeholders

This site uses only lightweight, code-created SVG photo placeholders. No AI-generated raster images are included in the website.

- `public/images/hero.svg`: hero seafood photo placeholder.
- `public/images/dried-fish.svg`: dried fish product photo placeholder.
- `public/images/crayfish.svg`: crayfish product photo placeholder.
- `public/images/prawns.svg`: dried prawns product photo placeholder.
- `public/images/pap.svg`: mixed-grain pap product photo placeholder.

Replace these placeholders with the business’s own photos and update paths in `src/order.js` and `src/main.jsx` if the file extensions change.

The fish emblem is an icon from Lucide. The story drawing is simple SVG code. The name beneath the story is typography, not a reproduced personal signature.
